# Customer Segmentation using RFM Analysis | Power BI

This project uses RFM (Recency, Frequency, Monetary) analysis to segment customers based on purchasing behavior. Interactive Power BI dashboards were created to analyze customer demographics, sales trends, and customer segments such as Champions, Loyal Customers, At Risk, and Lost Customers.

### Tools & Technologies

Power BI, DAX, Power Query, Data Modeling, RFM Analysis
